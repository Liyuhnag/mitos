# Deep Research

行业信息助手。面向智慧交通、金融科技、医疗健康、能源电力等行业，把检索、知识库、数据查询和多角色研究放在一次对话里完成。

## 项目介绍

分析师要回答一个行业问题，通常要同时查公开资料、内部文档、数据库和招投标信息，再自己整理成报告。Deep Research 把这些步骤收成一条研究链路：

1. 选择行业，发起研究或普通对话。
2. 系统按任务检索网页、政策、知识库和行业数据库。
3. 多个研究角色分工完成规划、取证、分析、审阅和写作。
4. 前端回放研究过程，并给出带来源的报告、图表和知识图谱。

后端基于 FastAPI，研究流程用可恢复的检查点保存进度。前端基于 React，会话、知识库、资讯、招投标、行业库和长期记忆都有独立页面。

本地依赖、环境变量和启动方式见 [READMED.md](READMED.md)。

## 项目亮点

- **多角色研究。** 架构师、检索、代码、数据分析、审阅和写作角色按图编排，研究步骤、检索结果和过程报告可以回看。
- **带来源的回答。** 联网检索、政策检索和知识库切片一起进入上下文，回答能回到文档片段和外部链接。
- **知识库闭环。** 支持上传文档、解析切片、向量化入库，并在页面里查看切片。
- **行业数据可问。** 行业库支持表结构浏览和自然语言查询，对话里可以直接展示证券卡片。
- **资讯和招投标。** 定时采集行业资讯，并按当前行业查看招投标信息。
- **会话可延续。** 会话、附件和长期记忆分开保存，后续对话可以沿用历史上下文。
